# Examples

- Always document attribution for imported or adapted examples: original project
  and authors, source URL, revision/date, original paths, license and local changes.
- Preserve copyright/license notices and include required license text. Check the
  actual files; a collection's headline license is not enough. Prefer permissive
  or public-domain examples; do not assume an unlicensed source is reusable.
- Distinguish upstream code from locally written repairs, harnesses and models.
  State unresolved provenance explicitly. Keep the record beside the example;
  use `upstream/SOURCE.json` and a license copy for vendored snapshots.
